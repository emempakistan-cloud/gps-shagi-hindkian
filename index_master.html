⚡ Quick Start (10 Minutes)

1 See the Demo (1 min)

Open index.html in your browser to see the UI demo.

2 Setup Azure (2 min)

Follow QUICKSTART.md to register a Microsoft app. Free and takes 2 minutes.

3 Install & Configure (3 min)

npm install
cp .env.example .env.local
Fill in your Azure credentials in .env.local

4 Run Locally (1 min)

npm run dev
Opens http://localhost:3000

5 Test (3 min)

Login → Create Teacher → Upload Document → Check OneDrive

❓ Frequently Asked Questions

Do I need to pay for anything?

No! Everything is free. Azure AD apps are free, Vercel has a free tier, OneDrive is included with a free Microsoft account.

What if I don't have Microsoft/OneDrive?

You can still see the UI demo (index.html) without any account. To test the full app, you'll need a free Microsoft account.

How long does setup take?

10 minutes for the quick start. Breaking down: 2 min Azure setup, 3 min installation, 1 min run, 4 min testing.

Can I deploy to other platforms?

Yes! It's a standard Next.js app. You can deploy to: Vercel, Netlify, Heroku, AWS, Google Cloud, Azure, etc.

Is the code production-ready?

Yes. It includes security, error handling, responsive design, TypeScript, and follows best practices.

Can I modify the code?

Absolutely! Read DEVELOPMENT.md for the code structure and how to add features.
